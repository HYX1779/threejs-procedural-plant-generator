# PhytoGenesis · 植物生成器

用数学和代码在浏览器里“种”出一株植物。

## 从分类到模型的代码路线

1. **分类**：在检索表里回答有没有种子、果皮，叶脉是网状还是平行，有没有根和茎叶。`classify()` 据此把植物分进七个类群之一。
2. **定形态**：`groupDefaults()` 按类群给出叶形、叶序、花瓣数、果实类型等默认值，再与滑块参数合并。
3. **建模型**：`buildPlant()` 拿着参数，用 `parts.ts` 的曲线和网格拼出茎、叶、花、果、根，用 `textures.ts` 现场生成叶脉、树皮等纹理，装配成 Three.js 模型。
4. **生长**：时间轴推进时，`model.update()` 按进度缩放、展开各部件，演示种子→发芽→成长→开花→结实。

参数相同，长出的植物就相同；改一个数，整株重长。
